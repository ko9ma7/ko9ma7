## 👋 About

Windows에서 **화면을 이해하고, 상태를 판단하고, 실제 입력으로 연결하는 비전 자동화 도구**를 만들고 있습니다.

현재 중심 프로젝트는 **VisionFlow Studio**이며, OpenCV 5, YOLO/ONNX, OCR, AOI, 대상 추적과 Windows 입력 제어를 하나의 작업 흐름으로 묶는 방향으로 개발하고 있습니다.

```text
CAPTURE  →  DETECT  →  TRACK  →  DECIDE  →  INPUT
```

|:--|:--|
| 👁 **Vision** | OpenCV 이미지 매칭 · YOLO/ONNX 객체 탐지 · OCR · AOI |

| 🖱 **Input** | 실제 커서 이동 · 정밀 접근 · Windows 입력 제어 |
