## 👋 About me

안녕하세요. **컴퓨터 비전과 Windows 자동화 기술을 실제로 사용할 수 있는 소프트웨어로 연결하는 개발자**입니다.

화면에서 대상을 찾는 것에 그치지 않고, **인식 → 추적 → 조건 판단 → 실제 입력**으로 이어지는 흐름을 설계합니다. 주요 관심사는 컴퓨터 비전, 안정적인 입력 제어, 데스크톱 소프트웨어와 사용자 중심 도구 개발입니다.

```text
  CAPTURE  ──▶  DETECT  ──▶  TRACK  ──▶  DECIDE  ──▶  INPUT
```

## 🚀 Featured Project · VisionFlow Studio

> **화면을 이해하고, 조건에 따라 동작하는 Windows Vision Automation / Workflow Studio**

**[📂 Source & Project Hub](https://github.com/ko9ma7/VisionFlow-Studio)** · **[📖 Documentation](https://ko9ma7.github.io/VisionFlow-Studio/)** · **[📦 Releases](https://github.com/ko9ma7/VisionFlow-Studio/releases)**

VisionFlow Studio는 화면 선택부터 대상 인식, 조건·반복 설정, 입력 실행까지의 작업을 한 흐름으로 구성하는 Windows 도구입니다. 이미지 탐색, YOLO/ONNX 기반 객체 인식, OCR, AOI 검사, 대상 추적과 마우스·키보드 입력을 연결하는 방향으로 개발하고 있습니다.

| 분야 | 주요 작업 |
| :-- | :-- |
| 👁 **Vision** | OpenCV 이미지 탐색 · YOLO/ONNX 탐지 · OCR · AOI 검사 |
| 🎯 **Tracking** | 동일 대상 추적 · 재탐지 · 이동/가림 대응 |
| 🧠 **Workflow** | 조건 판단 · 반복 작업 · 단계별 실행 구성 |
| 🖱 **Input** | 실제 커서 이동 · 정밀 접근 · Windows 입력 제어 |
| 🖥 **Platform** | Windows x64 · C# · .NET 8 · WPF |
| 🛡 **Reliability** | 실행 전 확인 · 기록 · 안전한 자동화 흐름 |

> **Legacy:** [YoloMacro-Distribution](https://github.com/ko9ma7/YoloMacro-Distribution)은 기존 YoloMacro 사용자와 이전 배포를 위한 별도 프로젝트입니다. 새로운 개발 및 문서는 **VisionFlow Studio**를 기준으로 확인해 주세요.
