# ko9ma7

Windows에서 화면을 이해하고 안정적으로 동작하는 비전 자동화 도구를 만들고 있습니다.

## VisionFlow Studio

VisionFlow Studio는 OpenCV 5, YOLO/ONNX, AOI, OCR, 장기 대상 추적과 실제 입력 제어를 한 작업 흐름에서 구성하는 Windows 비전 자동화 스튜디오입니다.

- [공개 다운로드와 문서](https://ko9ma7.github.io/YoloMacro-Distribution/)
- [최신 VisionFlow Studio 릴리스](https://github.com/ko9ma7/YoloMacro-Distribution/releases/latest)
- Windows x64, .NET 8, WPF
- OpenCV 5 이미지 매칭, YOLO 객체 탐지, AOI 검사, OCR
- 실제 커서와 Interception을 위한 부드러운 자연 경로 이동

YoloMacro 1.4.6은 호환성을 위해 보존된 레거시 제품선이며, 신규 개발과 최신 배포는 VisionFlow Studio에서 진행합니다.
